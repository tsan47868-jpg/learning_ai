Hans Mueller walks you from a blank terminal to a working AI feature. This is the session where "someday I'll build with AI" becomes a request you made yourself, with a response your own code received — keys, errors, and all.

## What You'll Learn

**Keys, Models, and Requests**
Hans explains the three concepts that trip up every beginner: API keys (how you authenticate), model names (what you call), and request shape (what you send). You will create a key, make a first call, and read the response line by line.

**Your First Working Example**
You will build a minimal, complete example: a script that sends a prompt and prints the answer. Hans keeps the code short on purpose — every line is something he can explain.

**Errors Are Information**
Rate limits, invalid keys, timeouts, model-not-found: Hans triggers each one deliberately and shows what it means. Most "AI is broken" moments are a status code telling you exactly what to fix.

**Cost, Limits, and Safety**
You will learn to track token usage, estimate spend before it surprises you, and handle keys safely — environment variables, never committed code, and rotation when one leaks.

## Who Should Attend

Developers new to AI APIs and technical beginners who know a little programming. Bring a laptop; leave with a working request and the confidence to read the docs alone.

*"Every integration expert has seen the same error messages as you. The difference is they know the error is halfway to the answer."* — Hans Mueller
